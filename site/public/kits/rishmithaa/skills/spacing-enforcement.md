# Spacing Enforcement

Use this skill when reviewing whether a page feels cramped, loose, or uneven.

## Core Rule

Spacing is structure. It tells the reader what belongs together and what changes context.

## Defaults

- Standard section: generous vertical padding.
- Major context break: more vertical room and a visual change.
- Standard card: roomy internal padding.
- Button: enough horizontal and vertical padding for the label to breathe.
- Small metadata: compact, but never cramped.

## Text Fit Rules

- Text must not touch a border, icon, or neighboring element.
- Buttons and pills must keep even left/right padding.
- Long labels should wrap or stop being pills.
- No overlapping text on mobile or desktop.

## Review Pass

Check:

- hero to first section gap
- label to heading gap
- heading to body gap
- card internal padding
- button label fit
- last section to footer gap
