# Frontend System

Use this skill before building or redesigning any page.

## Page Job First

Before choosing components, answer:

- Who is this for?
- What should they understand in five seconds?
- What action or decision should the page support?
- What existing references or brand inputs should guide the design?

## Default Page Families

- **Branded page**: introduce or position something.
- **Product surface**: help someone operate, scan, compare, or decide.
- **Editorial page**: teach, argue, or show evidence.
- **Concept mock**: make an idea concrete enough to react to.

## Build Order

1. Name the page job.
2. Define the five-second takeaway.
3. Choose the opening structure.
4. Build the primary working surface.
5. Add supporting context.
6. Review desktop and mobile.

## Rules

- Do not start with generic feature cards.
- Do not use in-page text to explain obvious UI.
- Use cards only when the card itself is a meaningful unit.
- Make actions stronger than explanations.
- Make text fit its container.
