# Text Breathing Room

Use this skill for pills, badges, buttons, dense cards, and text-heavy panels.

## Problem

Generated interfaces often technically fit text while still looking cramped. Good UI gives words enough optical space to read cleanly.

## Rules

- Short labels can use pills.
- Long explanatory text should not be forced into pills.
- Buttons need clear side padding and a stable height.
- Cards need enough padding that the text does not feel pasted to the edge.
- Eyebrows and metadata should sit close to the content they label.

## Fixes

- Increase padding before shrinking text.
- Let labels wrap if they are naturally long.
- Move secondary explanation outside the clickable shape.
- Use a list row instead of a pill cluster when labels become sentences.

## Done Standard

Every label, button, card, and panel should feel calm at both mobile and desktop widths.
