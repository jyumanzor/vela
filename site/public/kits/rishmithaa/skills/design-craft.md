# Design Craft

Use this skill when a page needs to feel intentional rather than generated.

## Design Mindset

Every component should answer: why does this help the visitor?

Before building a component, know:

- **Purpose**: what decision or action it supports
- **Placement**: why it belongs here
- **Hierarchy**: how important it is compared with the rest of the page

## Typography

- Use clear hierarchy: H1, H2, H3, body, labels.
- Do not use hero-sized type inside small panels.
- Use labels for metadata, not full explanations.
- Keep body text readable with generous line height.

## Components

- Buttons should name the outcome.
- Pills should be short and evenly padded.
- Cards should group real related content.
- Avoid nesting cards inside cards.

## Review Questions

- Does the first screen feel specific to this project?
- Can a visitor tell what matters without reading everything?
- Is there one primary visual idea?
- Does any section feel like filler?
