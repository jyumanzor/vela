# Color And Layout

Use this skill to keep pages readable, warm, and structured.

## Color Rules

- Use one primary accent.
- Do not use light accent colors as body text on light backgrounds.
- Use accent colors as fills, borders, highlights, or small markers.
- Make status colors mean something.
- Check contrast on every button and label.

## Layout Rules

- Give the page a rhythm: opening, primary content, supporting section, close.
- Use full-width bands or clean sections for major context changes.
- Keep cards for repeated items or framed tools.
- Avoid six identical sections stacked on one background.

## Visual Priority

The strongest visual treatment should land on the most important thing:

- the main action
- the key proof
- the current state
- the primary example

If five things are equally accented, nothing is accented.
