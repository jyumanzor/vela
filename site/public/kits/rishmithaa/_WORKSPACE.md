# Workspace — First Site

## Canonical Files

- Current app: `site/`
- Reference material: `ref/`
- Current page plan: `docs/page-plan.md`
- Current output notes: `_BUILD_LOG.md`

## Folder Structure

```text
first-site/
├── CLAUDE.md
├── _BUILD_LOG.md
├── _WORKSPACE.md
├── skills/
├── agents/
├── ref/
│   ├── screenshots/
│   ├── content/
│   ├── brand/
│   └── feedback/
├── docs/
└── site/
```

## Archive Rules

- Keep one current version of each output.
- Move older screenshots, mockups, and exports into `_archive/`.
- Do not leave multiple folders that all claim to be the current site.

## First Session

Start with one page. Define the page job, choose references, build, review, then log.
