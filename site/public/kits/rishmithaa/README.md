# Rishmithaa's Starter Kit

## What's Inside

- `CLAUDE.md` — the project rules file for a first website or interface
- `_WORKSPACE.md` — folder map and canonical output rules
- `_BUILD_LOG.md` — session history template
- `skills/` — front-end and operating skills
- `agents/` — review prompts for page critique

## Setup

1. Create a project folder.
2. Copy `CLAUDE.md`, `_WORKSPACE.md`, `_BUILD_LOG.md`, and `skills/` into it.
3. Add source material, screenshots, brand references, and notes under `ref/`.
4. Start Claude Code from the project folder.
5. Ask it to read `CLAUDE.md` and the relevant skills before building.

## First Build Rule

Start with one real page. Make the page useful before expanding the site.
